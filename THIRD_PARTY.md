# Sources and license status

No project-wide license file was supplied with the SOSR source snapshot. Packaging does not assign a new license to the code or derived data. The authors can add their chosen license after checking the distributed components.

- HSM encoder — [Sentence Transformers multilingual MPNet](https://huggingface.co/sentence-transformers/paraphrase-multilingual-mpnet-base-v2), with Apache-2.0 on its model card.
- LLM — [Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct), with Apache-2.0 on its model card.
- City instruction data/method — [CityGPT author repository](https://github.com/tsinghua-fib-lab/CityGPT). Follow the linked corpus's data terms as well as its code license.
- Roads — DIMACS 9th Implementation Challenge, supplied project copies with exact hashes.
- POI mapping and category taxonomy — supplied Foursquare-derived files. Upstream data attribution and redistribution terms should accompany a public data release.
- H2H/SPF and baseline C++ — retained source snapshot. Independent license notices for all components were not supplied.

Code versions are recorded in the Git history. Frozen data and reference checkpoint hashes are provided with their respective inputs and configurations.
